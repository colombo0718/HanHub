## 三、Ch 0：拼音與聲調入門（前置必修）

```
情境：第一次接觸中文發音系統
小春老師：「拼音不是中文，但是學中文的鑰匙。
          越南文用 a/b/c，中文也用 a/b/c——這部分你已經會一半了！」

教學重點
  1. 拼音 vs 越南文 quốc ngữ 的對照（同樣是拉丁字母，越南學生天然有優勢）
  2. 四聲（mā má mǎ mà）vs 越南文六聲（越南學生對聲調本來就敏感）
  3. 聲母 / 韻母 / 整體認讀音節

教學素材
  - 拼音 64 字學習卡（直接使用 XX 既有產品 Pinyin Poker 64）
  - 聲調手勢練習
  - 越南學生最常錯的 3 個發音（sh / x / r）

教學產出：學生能讀出任何標拼音的中文字
```

**設計理由**：拼音不教好後面全廢。Ch 0 是 XX 跟一般教材最不同的地方——真的把越南學生發音特性納入設計，而不是丟一張通用拼音表。

## 四、Ch 1：你好！（範式章節）

```
情境：第一次見面、打招呼、自我介紹
小春老師：「中文世界第一句話——你好。
          越南文 'xin chào' 是『請打招呼』，
          中文『你好』直接說『你 + 好』，更直白。」

新單字（12 詞）
  你 我 他 她 們 好 是 不 嗎 老師 學生 朋友

語法點
  ① 是字句：A 是 B（我是學生 / 他是老師）
  ② 嗎問句：肯定句 + 嗎？（你是老師嗎？）
  ③ 否定：不 + 是（我不是老師）

漢越詞利用 ☆
  你 (nỉ) ☆、好 (hảo) ☆、是 (thị) ☆
  學生 (học sinh) ☆☆、老師 (lão sư) ☆☆
  → 越南學生第 1 章就認得一半的字

情境對話（範例）
  A：你好！
  B：你好！我是 Linh，是越南人。你是中國人嗎？
  A：我不是中國人，我是台灣人。

學完能做
  ✓ 跟陌生人打招呼
  ✓ 自我介紹國籍身份
  ✓ 用「嗎」問句問對方
  ✓ 用「不」否定句子

colombo cameo 環節
  「跟真正的中文母語者第一次對話」
  學生用本章學到的句子問 colombo 三題，colombo 回應
```

> **2026-08-07 補充**：本章已合併原 Ch2「你叫什麼名字？」，正式量產時需在上面範式基礎上加入：新單字 什麼／名字／中國／越南／台灣／人／叫（14 詞）、語法點「什麼」問句與「的」所有格。範例對話可延伸為「你叫什麼名字？我叫 Linh，你呢？」
